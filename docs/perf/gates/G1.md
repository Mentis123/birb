## Amendment — F1, F2 and F3 closed in Wave 1 (orchestrator, Opus 5)

G1 recorded F1–F3 as *Wave 2 entry conditions* on the grounds that none can produce a false green
today. That reasoning is sound but the disposition was wrong, and it is reversed here.

The architecture of this programme is that oracles are **bought in one wave and spent in the next**.
Handing Wave 2's eleven cheap-tier tasks an oracle with a known laundering hole — and a note asking
the tasks themselves to fix it — inverts that. F1 in particular arms *precisely* when the first Wave 2
task lands, and disarms the two checks that guard the production-path ruling. A cheap agent cannot be
asked to notice that its own verifier went quiet.

All three are fixed in Wave 1's own deliverables and each was watched failing before and after.

### F1 — `--selftest` exited 0 with applicable mutations undetected

`doSelftest` printed a sentence for an applicable page-real mutation and pushed nothing onto
`failures`; the only guard fired on `applicable < catalogued`, which is false at exactly the moment
two mutations become applicable-but-unverified. The file's own header (line 56) already claimed it
"exits non-zero on any undetected APPLICABLE" mutation — the implementation contradicted its contract.

An applicable mutation with no verifier is now a failure naming the file that made it applicable.

```
# stub tree, src/ui/dev-{quality-panel,gesture}.js present — the case that used to exit 0
node tools/birb-quality.mjs --selftest   ->  exit 1
mutations: 24 catalogued, 24 applicable, 22 detected
SELFTEST FAILURES:
  M-A1-gesture-behind-debug ... APPLICABLE (src/ui/dev-gesture.js is on disk) but this harness has
    no live verifier for it. The task that created src/ui/dev-gesture.js must ship its verifier
    in the same change.
  M-A2-panel-opens-on-any-touch ... (same shape)
```

### F2 — `--check all` died with a TypeError instead of a finding

`checkStaticAvailability()` flips an assertion to available on mere file existence while
`LIVE_CAPTURES` covers a subset, so the first Wave 2 file took the whole board down with
`LIVE_CAPTURES[id] is not a function`. It failed loudly and so could not launder a green, but a stack
trace is not a diagnosis. A missing capturer is now a named `fail` on that assertion and the rest of
the board still runs. Verified in the stub tree: 0 TypeErrors, A1 and A2 reported with the gap named.

### F3 — A1 had no runnable automated flip

A1's only catalogued mutation was page-real, `QA-FLIP` covers snapshot-class only, and
`staticGreenFixtures()` had no A1 entry — so nothing ever executed a flip for it. The assertion was
sound (G1 drove it by hand), but "sound when someone remembers to check by hand" is the state R8
exists to forbid. Added a green A1 fixture (production-path load, panel opened) and a snapshot-class
mutation `M-A1-gesture-never-opens`. Now: `OK M-A1-gesture-never-opens -> fail`.
